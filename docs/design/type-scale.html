Muted captions implemented — italic dropped

Explanatory notes under a control (e.g. below "Hide tracks from streaming services"). Several currently use font.italic: true; dropping italic is worth considering — synthetic italics on a system font that has no real italic design tend to render as a crude slant, and the muted color + smaller size already carries the "secondary text" signal on its own.
