What each player generation does to a stick

The advisory rows on the statistics page come from this table. Players are grouped by the database they read, because that decides which measurement matters. Media-port USB versions are mostly undocumented by the manufacturers; where one is stated it is USB 2.0, except OPUS-QUAD's rear USB 3.2 port meant for SSDs. Nothing here uses UASP.

Seabass, rekordbox, Engine DJ		 Whatever the port negotiates: USB 2.0 tops out near 40 MB/s, USB 3 at 250–300 MB/s without UASP Seabass' scan stats every track file and walks the analysis folders: thousands of small operations, slow on a cold cache. — — Streaming for backups and exports, small random read for scans

Reference points for the small random read, 4 KiB at queue depth 1: a 2012-era USB 2.0 stick (SanDisk Cruzer Blade) about 0.9 ms; a current USB 3 stick 0.2–0.3 ms; a portable SSD about 0.2 ms. Sticks differ 4–5× on this and 15–30× on streaming.
